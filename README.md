# Power Consumption Detection

A machine learning-powered web application that predicts electrical power consumption based on key operational parameters such as voltage, current, and sub-meter readings. Built with Python and Streamlit, this project demonstrates how a trained Random Forest Regressor can be deployed as an interactive forecasting tool.

## Overview

Power consumption monitoring is essential for efficient energy management, equipment health assessment, and cost optimization. This application enables users to input electrical measurements and quickly estimate power usage in real time using a pre-trained machine learning model.

The app provides a simple, user-friendly interface for:

- Entering voltage and current values
- Providing sub-meter energy readings
- Generating a predictive power consumption estimate
- Visualizing the model output in a clean dashboard

## Features

- Interactive dashboard built with Streamlit
- Pre-trained Random Forest Regressor model
- Real-time power consumption prediction
- Simple numeric inputs for energy monitoring
- Clean and responsive UI for easy usage
- Lightweight project structure suitable for demo or educational deployment

## Model Details

The application uses a trained Random Forest Regressor to estimate power consumption from the following inputs:

- Voltage (V)
- Current (A)
- Sub Metering 1 (W)
- Sub Metering 2 (W)
- Sub Metering 3 (W)

The model predicts power consumption and displays the result in kW/hr.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Charchit-Gharai/Power_Consumption_Detection.git
cd Power_Consumption_Detection
```

2. Create a virtual environment (recommended):

```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

Start the Streamlit app with:

```bash
streamlit run power.py
```

Then open the local URL shown in the terminal (typically `http://localhost:8501`).

## How to Use

1. Open the app in your browser.
2. Enter the values for:
   - Voltage
   - Current
   - Sub Metering 1
   - Sub Metering 2
   - Sub Metering 3
3. Click the Predict button.
4. View the predicted power consumption value generated by the model.

## Example

An example of valid input could be:

- Voltage: 230 V
- Current: 8.5 A
- Sub Metering 1: 30 W
- Sub Metering 2: 45 W
- Sub Metering 3: 60 W

The model will estimate the overall power consumption based on these values.

## Notes

- This project is intended for demonstration and educational use.
- Model predictions are based on the trained dataset used during development and may require recalibration for production-grade deployment.
- For real-world industrial use, data quality validation and retraining with domain-specific data are recommended.
